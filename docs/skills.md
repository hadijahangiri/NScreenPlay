# Skills

Skills are instructional `SKILL.md` files for AI agents.

They live under `skills/<name>/SKILL.md` and currently include:

- `screenplay`
- `playwright`
- `reqnroll`
- `test-authoring`
- `test-review`
- `failure-analysis`
- `healing`

Skills are reference data for agents. They are not executable framework code.

The MCP server can list available skills and return the full content of a skill by name.
